| Dokumen | Kapan diperlukan |

`licenses/` menyimpan pemberitahuan lisensi wajib. Manifest dan build entry di `vendor/` dipertahankan untuk reproduksi library; tidak perlu dibaca saat task styling biasa.

Riwayat perubahan berada di Git. Laporan lama, snapshot berulang, dump hasil test dan duplikat upload telah dihapus. Simpan output besar di direktori sementara, lalu tulis hasil singkat di tasks.md. Jangan membuat ulang folder arsip/validation kecuali diminta. Screenshot, output tool dan dokumen yang tidak dibaca tidak otomatis memakai token; pembacaan berulang dan output besar yang menambah konteks kerja perlu dibatasi.
